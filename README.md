# GameCube-Banner-Editor-Converter
GameCube Banner Editor &amp; Converter

Check out the webapp here: [GameCube Banner Editor &amp; Converter](https://git2358.github.io/GameCube-Banner-Editor-Converter/)


### This is simply a simple Webapp GUI version of: 
[https://github.com/DarthMotzkus/cubiboot-new-ui/tree/main/tools/banner-converter](https://github.com/DarthMotzkus/cubiboot-new-ui/tree/main/tools/banner-converter)
[https://github.com/DarthMotzkus/cubiboot-new-ui/tree/main#homebrew-apps](https://github.com/DarthMotzkus/cubiboot-new-ui/tree/main#homebrew-apps)


### Info: 
- Make new `.bnr` 
- Edit existing `.bnr` - handy if you need to edit text, update icon...
- Preview how image will appear in the banner `"contain", "cover", "stretch"`


### Good to know: 
- loading existing `.bnr` will not modify the existing image, this way if you only update text and save, the image will not be degraded on save, if you need to edit the image, you must reload the new image file.
